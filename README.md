# OwnTime Clock App

A modern time tracking application available as a Progressive Web App (PWA) and for Android.

## Landing Page

The landing page provides an overview of OwnTime's features and download options. To view it locally:

1. Start a local web server in the project directory:
   ```bash
   python3 -m http.server 8080
   ```

2. Open your browser and navigate to `http://localhost:8080`

## Features

- 📊 **Time Tracking** - Effortless clock-in/clock-out interface
- 📱 **Cross-Platform** - Works on web, Android, and as a PWA
- 📈 **Analytics** - Detailed reports and productivity insights
- 🔒 **Privacy First** - Your data stays secure and private
- ⚡ **Lightning Fast** - Optimized for instant performance
- 🌙 **Dark Mode** - Beautiful light and dark themes

## Progressive Web App

OwnTime can be installed as a PWA on supported devices. The landing page includes:

- `manifest.json` - PWA configuration
- `service-worker.js` - Offline functionality
- App icons in multiple sizes (192x192, 512x512)
- Responsive design optimized for all screen sizes

## Technologies

- HTML5
- CSS3 (with modern features like CSS Grid and Flexbox)
- Vanilla JavaScript
- PWA with Service Worker
- Responsive design
